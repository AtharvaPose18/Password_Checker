# Password Strength Checker
A simple Java program that checks password strength based on its length and the presence of letters, digits, and special characters.

## Features
- Accepts password input from the user
- Checks for letters, digits, and special characters
- Classifies passwords as weak, medium, or strong

## Technologies Used
- Java
- Scanner class
- For loop
- If-else statements
- Boolean variables
- String and Character methods

## How to Run
1. Download PasswordChecker.java.
2. Open a terminal in the project folder.
3. Compile the program:
   javac PasswordChecker.java
   
4. Run the program:
   java PasswordChecker
   
## Purpose
This project was created to practise Java fundamentals, loops, conditional statements, string handling, and logical operators.
